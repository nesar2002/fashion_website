# Fashion Website

## About Project
This is a Fashion Website developed as a collaborative team project.

## Main Components
This project consists of three main components:

1. Announcement_Bar
2. Header
3. Page_Content

## Website Pages
The website contains 12 pages:

1. Home
2. Shop
3. Face Makeup
4. Eye Makeup
5. Lip Makeup
6. Hair Care
7. Skin Care
8. Personal Care Products
9. Perfumes & Colognes
10. Discounts
11. About Us
12. Contact Us
